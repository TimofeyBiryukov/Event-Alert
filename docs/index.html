Event Alert

High-signal Android calendar alerts, running entirely on-device.

Features How it works Open source

Never miss the events that matter.

Event Alert is a thin, native layer over your existing Android calendars. It reads upcoming events from the device, schedules high-signal full-screen alerts, and stays out of your way the rest of the time.

Features

High-signal alerts

Full-screen, easy-to-act-on alerts for upcoming calendar events, designed to be visible when normal notifications are not enough.

Simple setup

Pick which calendars to watch and how far in advance alerts should fire. No accounts, no backend, just your existing device calendars.

On-device & privacy-friendly

Event data stays on your device. The app reads calendars, schedules alerts, and never sends event details to a server.

How it works

  1. Read calendars: Event Alert reads upcoming events from the Android calendar provider.
  2. Schedule alerts: Events are mapped into internal models and scheduled using Android alarm/notification APIs.
  3. Show alerts: When it is time, you get a high-signal, native-feeling alert with dismiss and snooze actions.

For architecture details and edge cases, see the project README and docs.

Open source, small-scope project

Event Alert is a small open-source app maintained primarily for our own use. The public repo exists so we can version the code, keep release builds handy, and let others reuse or fork the idea if it is useful.

Issues and pull requests are welcome, but the scope is intentionally narrow: a lightweight alerts layer over existing calendars, not a full calendar client.
